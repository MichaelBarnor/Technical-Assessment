Stage 1 – Current Camera Preview Flow

Technical Assessment · Snapshot of the existing implementation (no blur pipeline yet)

Overview

The app is a Next.js 15 / React 19 client-rendered page. app/page.tsx renders a header ("Realtime Background Blur") and a single CameraPreview component. There is no backend and no video processing yet; the component displays the raw front-camera feed.

Camera Configuration

  • audio: false
  • video.facingMode: "user" (front camera)
  • video.width: { ideal: 1280 }, video.height: { ideal: 720 }

Flow

  1. Component mounts → useEffect calls startCamera() automatically.
  2. startCamera():
    1. If navigator.mediaDevices?.getUserMedia is missing → state unsupported, return.
    2. Set state requesting.
    3. Stop any existing stream and clear video.srcObject.
    4. Call getUserMedia(cameraConstraints).
    5. On success: store the stream in streamRef, attach it to <video>, await video.play(), set state ready.
    6. On failure: stop and clear the stream, set state blocked, show getErrorMessage(error).
  3. Start / Restart button → calls startCamera() again (disabled while requesting).
  4. Stop button → stopCamera() stops all tracks, clears srcObject, sets state idle (disabled unless ready).
  5. Unmount → effect cleanup stops all tracks.

Error Handling (Current)

ErrorHandled?Message
getUserMedia API missingYes"This browser does not support camera capture."
NotAllowedErrorYes"Camera permission was blocked. Allow camera access in the browser to continue."
NotFoundErrorYes"No camera was found on this device."
NotReadableError, OverconstrainedError, SecurityError, AbortError, play() rejectionGeneric"The camera could not be started."
Track ended mid-session (camera unplugged / permission revoked)NoUI stays in ready

UI

  • Status area uses aria-live="polite"; error text is styled with camera-error.
  • <video> is muted, playsInline, autoPlay.
  • A placeholder overlay is shown whenever state ≠ ready ("Waiting for the browser permission prompt." while requesting, otherwise the current message).

Not Yet Implemented
